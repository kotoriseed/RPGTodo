# RPGTodo

该文件后续需要根据项目情况更新，现在只是用于指示项目的一个原型说明文件。





以下是一段对该项目的简单介绍：

```
RPGTodo是一个用于管理日常todolist的web应用，他将TODO事项与RPG游戏的特色任务面板结合在一起，以增加用户每天制定和完成任务时的效率和乐趣。

关于TODO事项：
每一个TODO事项应当至少具有以下属性：任务难度、任务描述、任务目标、任务奖励、任务截止日期（类型有每日任务，每周任务，或灵活决定结束时间的任务）
任务可以嵌套，比如一个大任务下面包含一系列子任务

关于RPG特色：
- 任务可以以RPG游戏发布任务的形式渲染，完成任务后可以获得一系列奖励
- 该系统可以模拟一个角色，任务的完成可以帮助该角色升级装备等，每到一定时间周期结算时可以以打boss的形式来变相展示近期的任务完成好坏情况。
```
